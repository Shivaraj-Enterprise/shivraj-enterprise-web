# Install Motion

Add the `motion` animation library to the website without changing any existing animations.

## Steps
- Install the latest `motion` package.
- Keep the existing Framer Motion and Anime.js packages as they are; nothing on the site changes visually.
- Confirm the site still builds cleanly afterwards.

## Technical details
- Run `bun add motion`; imports become available as `motion/react`.
- No component edits in this step.
